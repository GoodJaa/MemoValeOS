# Decisions

Index of accepted decisions — about product and architecture, and about how work itself is carried out (branching, commits, review). A workflow decision is a Decision like any other: check here before the first git action of a session, not after.

> Create one note per decision from the Decision template. A decision is recorded when it is accepted, not when it is first proposed.

## Note

An accepted Decision is not automatically current knowledge. It stays `draft` until it meets the evidence floor in [[Knowledge-OS/Schema/Evidence-Schema]] — for a Decision, `L2` plus explicit acceptance — and each Decision records in its own Status section what was checked to get there.

Open technology questions are held in [[Uncertainties]], not here.
