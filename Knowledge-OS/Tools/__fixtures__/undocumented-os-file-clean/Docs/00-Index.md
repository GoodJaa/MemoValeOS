# Documentation index

Every file of the layer is named somewhere in Docs/, each in the form a page would write it:

- the validator, `validate-vault.mjs`, and its helper Knowledge-OS/Tools/helper.mjs;
- the command /mv-x — a longer name such as `mv-xy-other` would not have counted;
- the hook `budget-audit.cjs` and the fragment `settings.fragment.json`.

Test files are not tools: helper.test.mjs needs no page, and neither does the hook's test.
