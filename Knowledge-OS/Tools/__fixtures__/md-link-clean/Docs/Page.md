# Documentation page

Every form of Markdown link that names a real file, or no file at all:

- a sibling: [other](Other.md), and with an anchor: [part](Other.md#part)
- up a level: [readme](../README.md)
- from the vault root: [readme again](/README.md)
- a name with a space, two ways: [spaced](<Other Page.md>) and [encoded](Other%20Page.md)
- an image: ![diagram](diagram.svg "A diagram")
- an anchor in this page: [below](#below)
- not files: [site](https://example.com), [mail](mailto:owner@example.invalid)

Shown as code, so not links: `[gone](Missing.md)` and

```markdown
[gone](Missing.md)
```
