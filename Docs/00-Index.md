# MemoValeOS — документация разработчика

> **Описывает:** систему MemoValeOS (MVOS) целиком — слой [[Knowledge-OS/README|Knowledge OS]], структуру Project OS, инструменты, команды и способ доставки.
> **Связано:** [[Docs/01-Purpose-and-Principles]] — начните отсюда, [[Docs/11-Building-a-Similar-System]] — весь маршрут постройки на одной странице.

Здесь описано, как устроена каждая часть системы и почему она устроена именно так. Читатель — разработчик, который будет развивать MVOS или изучать её, чтобы построить подобную систему самостоятельно.

**Кому не читать.** Ассистенту. Как README.md и QA.md, эта папка написана для людей. `CLAUDE.md` запрещает загружать её как проектное знание, а провайдер контекста не отдаёт её ни при каких точках входа (`isWrittenForPeople()` в [[Knowledge-OS/Tools/context-provider.mjs]]). Канон для ассистента — `Knowledge-OS/Rules`, `Schema` и `Protocols`. Документация их объясняет, но не заменяет. Если страница и канон расходятся, прав канон, а страница устарела.

## Соглашения этой документации

- **Каждая страница начинается двумя строками.** «Описывает» содержит ссылки на элементы системы, которые страница документирует. «Связано» — ссылки на соседние разделы.
- **Тело страницы** состоит из разделов «Назначение», «Как работает», «Почему так», «Пример», «Подводные камни» и «Как менять».
- **Код упоминается по имени функции или константы, а не по номеру строки:** номера строк уплывают.
- **Ссылки ведут только на файлы слоя ОС.** Документация уезжает в апстрим, где задач, решений и находок проекта-носителя нет. Примеры из проекта-носителя пересказаны внутри страниц. С 2026-10-25 это проверяет валидатор: `docs-link-outside-os-layer`.
- **Ссылки проверяются валидатором.** `Docs/` входит в owned-область, поэтому битая ссылка — ошибка `broken-link`, а битая Markdown-ссылка `[текст](путь)` — `broken-md-link`. Frontmatter не нужен: папка не governed.
- **Каждый инструмент и каждая команда названы хотя бы на одной странице.** Иначе — `undocumented-os-file`. Это часть определения готовности любого изменения ОС ([[Docs/10-Extending]], «Готово, когда»; одной командой — [[Docs/06-Tooling/06-7-OS-Check]]).
- **Ссылки на файлы `.mjs` и `.json`.** Валидатор их разрешает, но Obsidian показывает их как неразрешённые, если в настройках не включено «Detect all file extensions».
